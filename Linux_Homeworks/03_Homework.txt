2. Управление группами:
a) создать группу;
b) попрактиковаться в смене групп у пользователей;
c) добавить пользователя в группу, не меняя основной;
d) удалить пользователя из группы.

svlight@gb-linux:~/home$ sudo useradd -s /bin/bash user10
svlight@gb-linux:~/home$ sudo passwd user10
passwd: password updated successfully
svlight@gb-linux:~/home$ groups user10
user10 : user10
svlight@gb-linux:~/home$ sudo usermod -aG sudo user10
svlight@gb-linux:~/home$ groups user10
user10 : user10 sudo
svlight@gb-linux:~/home$ sudo deluser user10 sudo
Removing user `user10' from group `sudo' ...
Done.
svlight@gb-linux:~/home$ groups user10

svlight@gb-linux:~/home$ tail /etc/group
...

svlight@gb-linux:~/home$ groups user10
user10 : user10 dev_team
svlight@gb-linux:~/home$ sudo groupdel dev_team
svlight@gb-linux:~/home$ tail /etc/group

3. Работа с группами.
a) Создать пользователя с правами суперпользователя. Проверить результат.
svlight@gb-linux:~/home$ sudo usermod -aG sudo user10
svlight@gb-linux:~/home$ groups user10
user10 : user10 sudo

b) * Создать группу developer и нескольких пользователей, входящих в неё. 
Создать директорию для совместной работы. Сделать так, чтобы созданные одними 
пользователями файлы могли изменять другие пользователи этой группы.

c) * Создать в директории для совместной работы поддиректорию для обмена файлами, 
но чтобы удалять файлы могли только их создатели.
