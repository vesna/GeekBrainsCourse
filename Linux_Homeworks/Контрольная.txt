1)   Используйте команды операционной системы Linux и создайте две новых директории – «Игрушки 
для школьников» и «Игрушки для дошколят»
svlight@gb-linux:~/home$ sudo mkdir "Игрушки для дошколят"
svlight@gb-linux:~/home$ sudo mkdir "Игрушки для школьников"
svlight@gb-linux:~/home$ ll
total 20
drwxrwxr-x  4 svlight svlight 4096 апр 28 00:38  ./
drwxr-x--- 18 svlight svlight 4096 апр 28 00:38  ../
-rw-rw-r--  1 svlight svlight    5 апр 18 15:31  test.txt
drwxr-xr-x  2 root    root    4096 апр 28 00:38 'Игрушки для дошколят'/
drwxr-xr-x  2 root    root    4096 апр 28 00:38 'Игрушки для школьников'/
----------------------------------------------------------------------------------------------

2)   Создайте в директории «Игрушки для школьников» текстовые файлы - «Роботы», «Конструктор», 
«Настольные игры»
svlight@gb-linux:~/home$ cd "Игрушки для школьников"
svlight@gb-linux:~/home/Игрушки для школьников$ sudo nano Роботы
svlight@gb-linux:~/home/Игрушки для школьников$ sudo nano Конструктор
svlight@gb-linux:~/home/Игрушки для школьников$ sudo nano "Настольные игры"
---------------------------------------------------------------------------------------------

3)    Создайте в директории «Игрушки для дошколят» текстовые файлы «Мягкие игрушки», «Куклы», 
«Машинки»
svlight@gb-linux:~/home/Игрушки для школьников$ cd ..
svlight@gb-linux:~/home$ cd "Игрушки для дошколят"
svlight@gb-linux:~/home/Игрушки для дошколят$ sudo nano "Мягкие игрушки"
svlight@gb-linux:~/home/Игрушки для дошколят$ sudo nano Куклы
svlight@gb-linux:~/home/Игрушки для дошколят$ sudo nano Машинки
-----------------------------------------------------------------------------------------------

4)   Объединить 2 директории в одну «Имя Игрушки»
svlight@gb-linux:~/home$ cp -a "Игрушки для дошколят"/ "Имя Игрушки"/
svlight@gb-linux:~/home$ cp -a "Игрушки для школьников"/ "Имя Игрушки"/
----------------------------------------------------------------------------

5)   Переименовать директорию «Имя Игрушки» в «Игрушки»
svlight@gb-linux:~/home/Имя Игрушки$ cd ..
svlight@gb-linux:~/home$ sudo mv "Имя Игрушки" "Игрушки"
-------------------------------------------------------------------------------

6)   Просмотреть содержимое каталога «Игрушки».
svlight@gb-linux:~/home$ cd Игрушки
svlight@gb-linux:~/home/Игрушки$ ll
-----------------------------------------------------------------

7)   Установить и удалить snap-пакет. (Любой, какой хотите)
svlight@gb-linux:~/home/Игрушки$ sudo apt install snapd
svlight@gb-linux:~$ sudo ln -s /var/lib/snapd/snap /snap
svlight@gb-linux:~$ sudo snap install snap-store
svlight@gb-linux:~$ sudo snap install chromium
svlight@gb-linux:~$ sudo snap remove chromium
-----------------------------------------------------------------------------------------

8)   Добавить произвольную задачу для выполнения каждые 3 минуты (Например, запись в 
текстовый файл чего-то или копирование из каталога А в каталог Б).
svlight@gb-linux:~/home$ nano test.txt
svlight@gb-linux:~/home$ crontab -e

*/3 * * * * cp /home/test.txt /home/test.txt.bak
